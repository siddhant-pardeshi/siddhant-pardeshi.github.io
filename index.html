P·01Full-stack application

BankNest

A full-stack banking web application.

Account workflows, transaction history, and atomic balance updates — built with Java, Spring Boot, MySQL, and React.

Java 17Spring BootSpring Data JPAMySQLReactReact RouterAxiosBootstrap 5
View repository ↗

Overview

A full-stack banking application with secure registration, login, and account management — plus a live dashboard for everyday account work.

Capabilities

  • Secure registration, login, and account management
  • 8+ RESTful APIs for deposits, withdrawals, fund transfers, and transaction history
  • Responsive React dashboard with transaction history and beneficiary management

Technical decisions

  • @Transactional keeps balance updates atomic and consistent across sender and receiver accounts — a failed transfer can never half-apply.
  • Backend organized into Controller, Service, Repository, and Entity/DTO layers so business rules live in one place.
  • A centralized Axios API layer on the React side keeps every screen talking to the same client.

Authentication mechanism is not documented publicly — no claims made beyond “secure registration and login”.

P·02Role-based platform

LifeDrop

A role-based blood donation management system.

Connecting donor, hospital, and admin workflows through structured requests, inventory management, and role-specific dashboards.

Java 17Spring BootSpring Data JPA / HibernateMySQLReact (Vite)React RouterAxios
View repository ↗

Overview

A three-tier, role-based platform for donors, hospital receivers, and admins — from registration and eligibility to request fulfilment and stock tracking.

Capabilities

  • 10+ REST APIs for authentication, inventory tracking, and the request workflow
  • Normalized MySQL schema: users, blood inventory, requests, donation camps — with enum-based statuses
  • 90-day donor eligibility check implemented in the application
  • Atomic inventory deduction when requests are fulfilled
  • Role-specific React dashboards with protected routes and a centralized Axios API layer

Technical decisions

  • Controller–Service–Repository layering keeps role rules and inventory math out of the controllers.
  • Enum-based statuses (Pending → Approved → Fulfilled) make the request state machine explicit and queryable.
  • Fulfilment deducts inventory atomically — stock counts and request states can't disagree.
  • The 90-day rule is a software check the project implements for donor eligibility.
